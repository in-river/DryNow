# DryNow

気象予報と物干し環境から、  
**「今から外に干して大丈夫か」**と**「何時ごろ乾くか」**を予測するFlutterアプリです。

天気を表示するだけではなく、洗濯物を外に干すかどうかという具体的な判断につなげることを目指して開発しています。

> 現在開発中です。  
> 乾燥時間予測には暫定的な係数を含んでおり、十分な実測による精度検証は今後行います。

---

## 主な機能

### 外干しできるかを判定

干し始めから乾燥完了までの時間別予報を確認し、雨や強風を考慮して以下のように総合的に判定します。

- 外干しできます
- 外干しできますが注意
- 室内干しがおすすめ
- 今回は判定できません

単に現在の天気だけを見るのではなく、**乾くまでの途中で天候が悪化しないか**も確認します。

### 衣類ごとの乾燥完了時刻を予測

次の3カテゴリを同時に予測します。

| カテゴリ | 衣類の例 |
|---|---|
| 薄手・速乾 | 肌着、靴下、速乾ウェア |
| 普通 | 綿Tシャツ、シャツ、フェイスタオル |
| 厚手・乾きにくい | パーカー、デニム、バスタオル |

ユーザーが干す時間を入力するのではなく、DryNowが未来の気象予報を使って乾燥完了時刻を推定します。

### 干し始める時間を変更

現在は次の開始時刻を選択できます。

- 今から
- +1時間
- +2時間
- +3時間
- +6時間

今すぐ干す場合だけでなく、少し時間をずらした場合も確認できます。

### 物干し環境を反映

初回設定で次の環境を登録します。

- 屋根・雨よけ
- 干す場所
- 風通し
- 日当たり

設定内容は端末に保存し、乾燥時間の計算や注意表示に利用します。

### 予測地点を変更

Open-Meteo Geocoding APIを利用し、地名から予測地点を検索できます。

## 乾燥時間予測の仕組み

現在アプリで使用しているのは**乾燥時間予測モデル v1**です。

主に次の情報を使います。

- 気温
- 湿度
- 風速
- 日射量
- 風通し
- 日当たり

気温と湿度からVPD（水蒸気圧差）を求め、風と日射の影響を加えた乾燥力を時間ごとに計算します。

その乾燥力を未来の予報に沿って積算し、薄手・普通・厚手それぞれの乾燥完了時刻を推定します。

ただし、現在の係数には暫定値を含みます。実際の衣類乾燥との対応は十分に検証できていないため、表示する乾燥時間は現時点では目安です。

詳細は [乾燥時間予測モデル v1](docs/DRYING_MODEL_V1.md) にまとめています。

## 気象APIの比較

DryNowでは、外干し判定や乾燥時間予測の入力となる気象データを選ぶため、複数の気象APIを比較しました。

比較対象は次の4サービスと気象庁AMeDASです。

- OpenWeather
- Open-Meteo
- Visual Crossing
- Tomorrow.io
- 気象庁AMeDAS

熊谷・東京・静岡・大阪・松山の5都市でデータを継続的に保存し、気温・湿度・風速・降水などを比較しました。

比較ではTomorrow.ioが数値上もっとも良い項目もありました。

一方でDryNowでは、数値上の誤差だけでなく、

- 時間別予報
- 日射量
- 降水確率
- 必要な気象項目
- 利用条件
- 開発・検証時の扱いやすさ

も含めて検討し、現在は**Open-Meteo**を採用しています。

詳細は [API比較結果](docs/API_COMPARISON_RESULT.md) にまとめています。

## 乾燥時間モデル v2

v1では、気象条件から求めた乾燥力を積算して乾燥時間を推定しています。

一方、実際の衣類乾燥では、

- 脱水直後の水分量
- 素材
- 衣類の厚さや構造
- 乾燥初期と後半の違い
- 高湿度時の平衡含水率

なども影響します。

そこで現在、衣類に残る水分量を状態として扱う**乾燥時間モデル v2**を、本番モデルとは分けて試作しています。

v2では、

- 恒率乾燥と減率乾燥
- 平衡含水率
- 5分刻みの状態計算
- 時間別予報への接続
- 高湿度時の乾燥停止
- 綿・ポリエステルの文献値を利用した平衡含水率モデル

などを扱っています。

現在の本番画面で表示している乾燥時間はv1の結果であり、v2はまだ本番画面には接続していません。

また、v2についても実測による十分な調整は行っていません。

詳細は [乾燥時間モデル v2](docs/DRYING_MODEL_V2_DESIGN.md) にまとめています。

## 現在の課題

乾燥時間の予測には、まだ多くの不確実性があります。

現在のモデルでは、特に次の項目を十分に扱えていません。

- 衣類ごとの正確な初期含水量
- 素材や縫い目、重なりの違い
- 実際の物干し場所の局所的な風
- 夜間の再吸湿
- 結露や夜露
- 雨による濡れ直し

また、気象予報自体にも誤差があります。

そのため、プログラムのテストが成功していることと、実際の乾燥時間を正確に予測できることは分けて考えています。

今後は実際の衣類を用いた記録を増やし、予測結果との差を検証していきます。

## 開発の背景

DryNowは、Flutterと外部APIの学習として制作した天気アプリから始まりました。

開発を進める中で、

**「天気を表示するだけではなく、その情報を実際の行動につなげられないか」**

と考え、洗濯物の外干し判断を支援するDryNowへ発展させました。

初期のWeather App完成時点は、Gitタグ `weather-app-v1` として残しています。

---

## 今後

現在は機能を増やすことよりも、**乾燥時間予測の根拠と検証を強くすること**を重視しています。

今後は、

- v1の実測検証
- v2と実測結果の比較
- 衣類ごとの違いの検証
- 高湿度時の乾燥挙動の確認
- 予測誤差の評価

を進めます。

最終的には、

**「天気を見るアプリ」ではなく、「洗濯物をどう干すか判断できるアプリ」**

として使える状態を目指しています。
