# 外干し判定 v1

2026-09-17実装。採用APIはOpen-Meteo。現在値または指定時刻の時間別予報から説明可能なルールで適性を返す。
閾値はDryNowの**暫定的な製品ルール**であり、気象機関の安全基準や乾燥実験から確定した数値ではない。

## 入出力と優先順位

`lib/drying_assessment.dart` はHTTP・Flutter・API固有JSONに依存しない。
`DryingEvaluator.evaluate(DryingConditions, now: ...)` に現在時刻を明示的に渡せるため、境界値と鮮度を再現可能に検証できる。
結果は `suitable`（適性あり）、`caution`（注意）、`notRecommended`（NG）、`unknown`（判定不能）と複数の日本語理由。

| 優先 | 条件 | 結果 |
|---|---|---|
| 1 | データ時刻なし、60分より古い、5分より未来 | 判定不能 |
| 2 | 降水量 > 0 mm、または雨・雪・雷雨コード | NG |
| 2 | 風速 ≥ 8 m/s | NG |
| 2 | 有効な降水確率 ≥ 60% | NG |
| 3 | 気温・湿度・風速欠損、現在の降水状況が不明、不正な数値 | 判定不能 |
| 4 | 5 ≤ 風速 < 8 m/s、または風速 < 1 m/s | 注意 |
| 4 | 気温 < 10℃、または湿度 ≥ 80% | 注意 |
| 4 | 30 ≤ 降水確率 < 60% | 注意 |
| 5 | 上記に該当しない | 現在の条件では適性あり |

- 気温・湿度・風速・降水量の `0` は有効値。NULL/欠損を0へ変換しない。
- 非有限値、負の風速/降水量、範囲外の湿度/確率（0～100%以外）は不正値。気温は-100～70℃、風速は0～150m/sを妥当範囲とする。
- 他項目が欠損しても、鮮度が有効で確実に分かる降水や強風のNGは維持し、欠損理由も返す。
- 雨量0と降水コードが矛盾した場合はNG。雪・着氷性の降水・雷雨も対象にする。
- 現在値判定では降水確率は任意入力、予報判定では必須入力。未取得を0%と見なさず、確率0%だけで現在の降水なしとは判定しない。

## APIと画面の接続

- `WeatherApi` がOpen-Meteo `/v1/forecast` の `current` を取得する。春日部駅周辺の既存検証座標 `35.9795, 139.7523` を使用。
- 気温℃・湿度%・風速m/s・降水mmを明示し、レスポンスの単位も確認する。降水は雨・雪等の合計で、`current.interval` の時間窓を保持する。
- `timeformat=unixtime` / `timezone=GMT` でデータ対象時刻をUTCに正規化する。取得時刻とは別に保持し、画面では端末時刻で表示。
- `Weather` はAPIの格子座標と対象時刻、欠損値を保持し、`dryingConditions` で判定入力に変換する。元JSONは `WeatherResponse.rawJson` に別途メモリ保持し、ログには出力しない。
- 取得エラー時は再読み込み。通常表示中は毎分およびアプリ復帰時に鮮度を再評価する（自動API再取得はしない）。
- APIキーは不要。Flutterの `.env` 読込・アセット同梱を停止した。Python収集用の `.env` は従来どおり利用できる。
- 画面にデータ提供元・ライセンスURL・加工の説明を表示する。
- v8では同じForecast APIの `hourly` から気温・湿度・風速・降水量・降水確率・weather codeを取得し、指定時刻に最も近い30分以内の予報を `evaluateForecast` へ渡す。
- 予報時刻は現在値の60分鮮度判定とは分離し、時刻欠損または過去の予報を判定不能とする。予報評価では降水確率を必須入力とする。

## v1の範囲と次の作業

v8で時間別の降水確率を正式に接続した。指定した干し始め1時点の適性であり、洗濯物を干している数時間の安全や乾燥完了を保証しない。乾燥時間推定は未実装。

1. 干す時間の長さを定義し、開始から終了まで複数の時間別予報を評価する。
2. 雨・強風・低温を含む実際の外干し結果で閾値を検証する。突風は平均風速と別に扱う。
3. gust・雲量・露点・日射量を追加し、衣類/日当たり条件と併せて乾燥時間推定を検討する。
4. 商用公開前にOpen-Meteo有料契約とサーバー経由のキー管理・回数制御を設計する。

API仕様: [Open-Meteo Forecast API](https://open-meteo.com/en/docs)。
